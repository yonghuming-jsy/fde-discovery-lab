Tenant-aware access

分层权限

权限必须在服务端按租户、角色和组织单元校验；隐藏界面按钮不能替代访问控制。

MVP 角色与范围
依据项目技术方案
角色管理范围知识访问可执行操作
平台管理员平台级租户默认不能读取租户文档正文创建租户和首位租户管理员
租户管理员单一租户本租户全部组织单元管理成员、组织树和知识库
组织单元管理员所属单元及其子单元授权范围内的知识库管理范围内成员和资料
普通用户个人及明确授权范围租户共享或所在单元知识库提问、查看已发布 Wiki
i平台管理员不会因平台角色自动获得租户文档访问权；跨租户访问默认拒绝。所有业务 API 需要做服务端授权检查。
